# Code of Conduct

## Preservation of Library

This repository serves as a mirror to the one containing the canon libgourou library. As such, the
original, unmodified code is provided with next to no exceptions, and the only deviation from the
source is the inclusion of the uPDFParser library required to compile libgourou.

All code is obtained from the [official upstream](https://forge.soutade.fr/soutade/libgourou) and
directly copied over. Any modifications made to the code will be clearly identified by being
stored in a branch secondary to the `main` branch.


## Contributions

Any outside contributions made to the `main` branch will not be accepted. If you wish to make a
significant change to the codebase, it must be done in a branch. Again, the primary goal of this
repository is preservation due to Soutade's Git instance having protections that make cloning
difficult. Contributions made will be manually reviewed before being accepted. Any
excessively-large contributions that cannot manually be reviewed in a reasonable timeframe will
probably be rejected.


### Generative AI

While I do not like generative AI, I do understand that it is a tool commonly used in the industry,
especially as a companion for writing code. As such, code written using generative AI agents will
be accepted, with caveats. It will still undergo the manual review process with the same conditions
as human-generated code, but will also most-likely warrant further investigation. Because of the
additional man-power required for these reviews, the size threshold for commits using generative AI
will be much smaller.
